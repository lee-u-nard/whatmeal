- Use the real Android release on two phones, **A: household owner; B: a different member account**. Both accounts must already be verified, signed in, and members of the same authorized household. Do not show passwords, provider keys or invitation values on the projector.
- Rehearse on the exact installed APK. Actual two-physical-phone acceptance has **not** been performed by the coding agent. Source inspection and automated tests are not a substitute.
- Fill a private cue card with the **actual** household name, selected planned-for profile, manual recipe name and ingredients, chosen date, backup plan name, completion-ready meal, pantry item and grocery item. These documents intentionally supply no invented accounts, credentials or food records.
- Preconfigure the creator for **one day, Dinner, an existing planned-for profile and one cuisine**. Return A to Home. B must have the real, already saved backup plan accessible. Verify its date and ingredients beforehand.
- Jabez's manual dish must use a genuine recipe your team has reviewed. Prepare its real ingredient text so it can be entered quickly. Do not save blank placeholder meals.
- The live AI dialog **cannot be cancelled**. If it is still open at **03:25**, continue on B using the saved backup. Leave A's request alone. Later, an unsaved result or pending save on A is also a reason to skip the live two-phone update; do not discard it just to navigate.

## Fixed fallback rules

- **Slow AI at 03:25:** switch the displayed workflow to B. Say it is a previously saved plan. Do not retry, force-close, tap Back through the modal, or claim a fresh result.
- **Save failure:** say the result is not confirmed saved; keep the draft open. Use B's already saved plan. Never choose **Discard** to hide a failure.
- **No recommendation/photo:** show the actual empty state or intentional image fallback. Neither establishes an AI failure or successful image match.
- **Completion blocked:** show a real existing completed record and state that it was completed earlier. Do not invent pantry stock or disable checks.
- **No shared update/inbox event by the slot end:** explicitly mark that live step unconfirmed and continue with a real existing view.
- If a presenter is behind, omit a month-navigation tap or the optional new grocery row. Keep all four 2:30 boundaries. Do not speed-read the entire code guide.
