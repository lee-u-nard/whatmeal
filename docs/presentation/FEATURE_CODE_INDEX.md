## Extended trace: manual and AI are different entry paths

**Manual:** `_createCustomMealPlan` → `GeneratedPlanDraft` with empty authorable slots → editor `_showEditMealDialog` → `mealsForSaving` drops untouched slots → explicit `_saveDraft` → `SavedPlansRepository.savePlan` → Firestore plan plus nested meals → `watchSavedPlans` → calendar/details.

**AI:** `_generateMealPlan` → `GenerationInventory.capture` and synchronized settings → `LlmService.generateMealPlan` → `AiProviderFactory` → actual provider adapter → prompt/HTTP or retained SDK → JSON parser → meal/slot/restriction validation → result with actual provider/model → **unsaved** draft → explicit save path above.

**Shared pantry/inbox:** edit sheet → `PantryRepository.updateItem` → `PantryStore.write` transaction saves item and household event → member's pantry listener and `HouseholdActivityStore.watch` → rendered update/inbox → own receipt through `NotificationService.markRead` → `notificationRoute`.
